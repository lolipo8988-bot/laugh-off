# One-Line Laugh-Off — entry

A tiny Python program (`main.py`) that writes exactly one original funny line to
`/output/entry.txt` for the [One-Line Laugh-Off](https://make.fun/competitions/u-zkhiel-one-line-laugh-off-714618ae)
competition on make.fun.

The joke: a smartwatch mistakes an existential crisis for deep sleep — and
congratulates its owner on a personal best. It aims for a hard, sudden laugh on
a cold read: a familiar wearable-health setup, an unexpected turn, and a second
punch in the last three words, with every word earning its place.

## Run

```sh
python3 main.py
# writes /output/entry.txt (override the path with ENTRY_OUTPUT for local tests)
```
